Instalação e Conexão com Dbeaver no linux ubuntu

A instalação do Dbeaver é feito atraves do seguinte link
https://dbeaver.io/download/

Já no servidor basta entrar no terminal e digitar o seguinte comando: <p>
sudo snap install dbeaver-ce --classic

Ao terminar no menu vai aparecer o icone do dbeaver
<img width="1279" height="793" alt="image" src="https://github.com/user-attachments/assets/a09eeb80-96b5-415a-9c0a-ea153d50ab93" />


Ao entrar no dbeaver, veremos que contem um SQLite já pronto para ser usado.
Para a gente fazer a conexão basta clicar no icone do + para ser feito uma nova conexão.
